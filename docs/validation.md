# 公開版の検証と残課題

2026-10-27 / Windows / Node.js 24.22.1。公開用に切り出した版を検証した記録です。
元の運用版の検証結果や利用実績を、この公開版での実機検証として流用していません。

## 実施

- TypeScript型チェック・ビルド成功。
- 17件のテスト成功。認証時の実メール照合、不一致時に既存トークンを上書きしないこと、
  保存済みトークンの照合、予定更新のIf-Match・412時の扱いをモックで確認。
- stdioのMCP接続で、demo/read-onlyとgoogle/read-onlyは8ツール、google/write-enabledは13ツール。
  account必須の入力スキーマと、demoで架空データを返すことを確認。
- 静的な公開混入検査で、管理外設定・鍵のパターン・非見本メール・内部IP・ユーザー固有パスを検査。
  値そのものをエラーやログに出さない。
- SDK・googleapis・zod・テスト環境と推移依存を更新。監査のhigh/criticalは0。
- 元の非公開repo、既存MCP登録、本番アカウント設定・トークンには変更を加えていない。

## 依存監査の残課題

`npm audit`にはmoderateが2パッケージ残る：`gaxios`とその依存`uuid`。
`@google-cloud/local-auth`の認証ライブラリが使う推移依存で、通常のaudit fixでは解消しなかった。
現行gaxiosの該当コードはuuid.v4()を引数なしで呼ぶ。報告対象はv3/v5/v6等へバッファを渡す経路であり、
確認した呼び出しにはその条件がない。ただし、依存全体の安全性を証明したという意味ではない。
上流更新を追い、互換性未検証のメジャーoverrideは加えていない。

参考：[uuid advisory](https://github.com/advisories/GHSA-w5hq-g745-h8pq)。
